usage: batch_markdown.py [-h] --markdown-file MARKDOWN_FILE
                         [--output-dir OUTPUT_DIR] [--prompt PROMPT]
                         [--sections SECTIONS] [--overwrite] [--limit LIMIT]
                         [--model MODEL] [--save-diagnostics]
                         [--save-page-source]
                         [--max-section-attempts MAX_SECTION_ATTEMPTS]
                         [--download-timeout DOWNLOAD_TIMEOUT]
                         [--close-delay CLOSE_DELAY]
                         [--chrome-profile-dir CHROME_PROFILE_DIR]
                         [--output-ext OUTPUT_EXT] [--no-warm-up]
                         [--keep-browser] [--manifest MANIFEST] [--no-resume]
                         [--retry-failed] [--adopt-existing]

Process each ## section in a Markdown file with a prompt and download the
generated artifact.

options:
  -h, --help            show this help message and exit
  --markdown-file MARKDOWN_FILE
                        Markdown file with ## section headings
  --output-dir OUTPUT_DIR
  --prompt PROMPT
  --sections SECTIONS   Comma-separated section numbers or ranges, e.g.
                        20,21,22 or 20-22.
  --overwrite
  --limit LIMIT
  --model MODEL
  --save-diagnostics    Save diagnostics for every failed retry; final
                        failures are always saved.
  --save-page-source    Include potentially sensitive page_source.html in
                        failure diagnostics.
  --max-section-attempts MAX_SECTION_ATTEMPTS
  --download-timeout DOWNLOAD_TIMEOUT
  --close-delay CLOSE_DELAY
  --chrome-profile-dir CHROME_PROFILE_DIR
  --output-ext OUTPUT_EXT
                        Output file extension (opml or md)
  --no-warm-up          Skip the initial hello warm-up message when opening
                        ChatGPT.
  --keep-browser        Do not close the browser when the batch finishes.
  --manifest MANIFEST   Manifest path (default: <output-dir>/manifest.json)
  --no-resume           Ignore resume decisions and run selected jobs again;
                        results are still recorded.
  --retry-failed        Only run sections previously failed, interrupted,
                        pending, or invalidated in the manifest.
  --adopt-existing      Validate and register untracked existing outputs
                        instead of rebuilding them.
